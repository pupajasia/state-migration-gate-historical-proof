# Support

Use GitHub issues for reproducible defects, documentation gaps and voluntary
founding-pilot interest. Search existing issues first and share only synthetic,
non-confidential examples.

Include the action tag or commit, runner image, redacted contract, expected
verdict and actual report. Never post credentials, private release URLs,
customer data or proprietary application artifacts.

This project is currently an experimental release candidate. No response time,
uptime or compatibility commitment is offered.

Do not disclose a suspected vulnerability in a public issue. Private
vulnerability reporting or another private security route must be enabled by
the repository owner before broad release.
